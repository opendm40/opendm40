Как подключить мультиметр

Включите Bluetooth на DM40 и откройте экран мультиметра. Выберите Bluetooth LE, нажмите «Подключить» и выберите прибор в системном окне браузера. Закройте другие приложения, уже подключённые к DM40.

Автономный dm40.html можно открыть напрямую в Chrome/Edge. В Chrome на Linux откройте chrome://flags/#enable-experimental-web-platform-features, выберите Enabled и нажмите Relaunch. Это необходимо, если Web Bluetooth отсутствует. Firefox и Safari не поддерживают этот способ подключения. Если браузер ограничивает доступ из локального файла, используйте localhost или HTTPS.

Для Web Serial сначала выполните сопряжение Bluetooth Classic-интерфейса DM40 в настройках Bluetooth ОС. Затем выберите Web Serial / RFCOMM → Подключить → устройство DM40 (оно может называться C-1-ATK-DM40-CALI, тогда как BLE-интерфейс называется DM40A). Chrome 117+ умеет работать с сопряжённым Serial Port Profile напрямую: создавать /dev/rfcomm не требуется. Этот способ проверен в Chrome 144 на Linux без экспериментальных флагов.

HOLD, REL и выбор режима отправляются на прибор. Изменения отображаются по ответным измерениям. Деморежим использует искусственные данные и не подключается к оборудованию.

Настройки подключения

Модель уточняется при подключении. Вручную задаёт подписи диапазонов, если автоопределение недоступно.

Скорость применяется при следующем подключении. Для эмулируемых Bluetooth-портов обычно игнорируется.
