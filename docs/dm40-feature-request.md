# Alientek DM40C — Feature Request / UX Gap Analysis для альтернативной прошивки

**Версия:** 1.0, 2026-10-13
**Статус:** черновик для разработки собственной прошивки
**Базовая прошивка для сравнения:** стоковая V2.x (мануал V1.5, changelog до V2.1)

---

## 0. Как читать документ

- **[Факт]** — подтверждено мануалом, разбором платы или измерением владельца.
- **[Вывод]** — моё заключение из состава компонентов и поведения прибора; надо проверить на железе.
- **[?]** — неизвестно, требует проверки.
- Приоритеты: **P0** — без этого прибор уступает любому Fluke за $300 в ежедневной работе; **P1** — заметно улучшает UX; **P2** — приятно, но не критично.
- Трудоёмкость: **S** (дни), **M** (недели), **L** (месяц+), ориентировочно для одного разработчика, уже знакомого с платформой.
- **FW** — реализуемо прошивкой на текущем железе; **HW** — требует изменения платы.

Источники: ветка EEVblog «AlienTek DM40C New Multimeter», обзор EEVblog #1723 (Dave Jones), разбор на mydigit.cn (через пересказ jebem), обзор на mysku.club, мануал DM40 V1.5, changelog прошивок.

## 1. Железо: что есть и что из этого следует

### 1.1 Где описано железо

Состав платы, пины, фронтенды, питание и источники (BOM платы V1.1 от jebem в ветке EEVblog по разбору на mydigit.cn, фото, код стока и fw-rs) собраны в одном месте: [hw/README.md](../hw/README.md). Основное: [перечень компонентов](../hw/README.md#main-parts), [блок-схема](../hw/README.md#block-diagram), [таблица пинов](../hw/README.md#pin-table), [открытые вопросы и противоречия](../hw/README.md#unknowns). Здесь остаются только выводы для функций и UX.

### 1.2 Гальваническая развязка [Факт, владелец 2026-10-24]

Мультиметр (HY3131, опорник, делитель, реле, шунты, banana-гнёзда) гальванически развязан от MCU; MCU, USB, осциллограф и генератор, по выводу, сидят на одной земле с батареей и USB. Схема развязки и аргументы: [hw/README.md, Block diagram](../hw/README.md#block-diagram) и [Isolation boundary](../hw/README.md#isolation-boundary).

**Что это значит для прошивки:**
- DMM можно безопасно использовать во время зарядки — стоковый запрет избыточен. Реальная опасность только для осциллографа/генератора (их земля = USB GND = земля ПК/зарядки).
- Одновременная работа DMM и осциллографа/генератора электрически допустима; стоковое отключение генератора в режиме DMM — скорее всего конфликт ресурсов (таймер/DAC/DMA), не изоляция. [?]

### 1.3 Ресурсы, которые стоковая прошивка не использует

| Ресурс | Есть | Сток использует | Можно использовать для |
|---|---|---|---|

## 2. Инвентаризация стокового UX (baseline)

### 2.1 Экран мультиметра [Факт, мануал 2.2]
- Верх: статус-бар (AUTO, RUN/HOLD, таймер, замок тача, батарея, BT).
- Слева 4 софт-кнопки: **MF** (меню/пределы/настройки режима), **Старт/Стоп** (= HOLD), **AUTO/AUTO+**, ручной предел.
- Центр: главное показание (крупные жёлтые цифры) + **Aux1** + **Aux2**.
  - Aux1: частота (AC), AC-компонента (AC+DC), температура прибора (режим T).
  - Aux2: скважность (AC/Hz), DC-компонента (AC+DC), % сигнала 4–20 мА (DC mA), эквивалентное сопротивление (диод), °F (режим T).
- Низ: 6 кнопок на 8 функций (V, A, Ω, C, диод/прозвонка, Hz/T); функции с общей кнопкой переключаются повторным нажатием.

### 2.2 Функции [Факт]
- V: DC / AC / AC+DC (B, C); пределы 600 мВ … 1000 В; вход 11.1 МОм DC, 4.3 МОм AC (измерение Taimer81).
- A: один разъём на все диапазоны, автопереключение MOSFET; DC / AC / AC+DC.
- Ω: обычный и «Online» (внутрисхемный, пониженное тестовое напряжение); быстрый цикл по кнопке Ω.
- C: 6 нФ … 60 мФ, только авто-предел; паразитная ~32 пФ прибора + ~30 пФ щупов.
- Диод 0–3 В; прозвонка с режимами звука (непрерывный / короткий / тройной).
- Hz 10 Гц … 60 МГц (реально: 50 мВpp до ~100 кГц, 1.7 Vpp на 10 МГц, 6 Vpp на 20 МГц), скважность.
- T: −40 … +1000 °C, термопара.
- REL (RLE); сбрасывается при смене режима.
- HOLD ручной.
- Тренд-график: 160 / 320 / 640 мс/дел.
- Память показаний: 5 ячеек по тапу на цифры; стираются при выключении.
- Скриншот: свайп тремя пальцами вниз → файл на U-диск; просмотр только с ПК.
- Выключение: свайп двумя пальцами вниз; долгое нажатие кнопки; двойной клик — замок тача.
- Настройки: язык (CN/EN), затемнение 5/10/30 мин, автовыключение 10/30/60 мин, яркость, громкость, USB-режим, сброс, антивибрационный режим, mode memory, countdown shutdown.
- BT: приложение Android/iOS зеркалирует экран (только модель C); меню частично на китайском.
- Генератор: синус/пила/треугольник 1 Гц–50 кГц, меандр 100 кГц–10 МГц, 0.5–3.0 Vpp, DC-offset фиксирован = Vpp/2, выключается в режиме DMM.

### 2.3 Что стоковая прошивка делает хорошо (сохранить)
- Скорость прозвонки и автодиапазона.
- Крупные цифры, читаемость с расстояния.
- Тренд-график как стандартный элемент экрана.
- AC+DC с раздельным отображением компонент.
- Проценты 4–20 мА, сопротивление диода в Aux.
- Скриншот жестом из любого режима.
- Один токовый разъём.
- Загрузка в последний режим.

## 4. Feature requests

Формат каждого пункта: **ID · Название · [Приоритет / Трудоёмкость / FW|HW]**, описание, критерии приёмки, заметки по реализации.

### 4.1 Измерительное ядро

#### FR-01 · AutoHold · [P0 / M / FW]
Захват показания после стабилизации, подтверждение звуком, автоматическое обновление при новом стабильном значении.
- Критерии: включается софт-кнопкой или долгим нажатием HOLD; при изменении входа более чем на X % предела и последующей стабильности в пределах Y отсчётов за T мс — писк + фиксация; индикатор AHOLD в статус-баре; при OL не фиксировать.
- Реализация: алгоритм в духе Fluke — окно стабильности 1 с, порог изменения 2 % предела (параметры в настройках); работать на данных АЦП, а не на отображаемых значениях.
- Также: **Touch Hold** — HOLD по тапу на главную цифру (сейчас тап пишет в ячейку памяти; перенести запись на долгий тап или в меню).

#### FR-02 · MIN / MAX / AVG · [P0 / M / FW]
- Критерии: отдельный экран или панель с MIN, MAX, AVG, текущим значением и временем от старта; время события MIN/MAX; сброс; работает в любой функции; сохраняется при смене предела (AUTO) с корректным пересчётом.
- Реализация: обновлять на полной частоте АЦП HY3131, не на частоте дисплея; аккумулятор AVG в double/int64; время от RTC или монотонного таймера.
- Автовыключение в этом режиме запрещено (см. FR-10).

#### FR-03 · Peak detect · [P1 / M / FW, частично HW]
- Критерии: захват пиков положительной/отрицательной полярности с длительностью ≥ 1 мс (цель; 250 мкс — если быстрый АЦП HY3131 позволяет, уточнить по datasheet).
- Реализация: быстрый 19-bit канал HY3131 в режиме непрерывного сэмплирования; фильтр против шумовых выбросов (2–3 последовательных отсчёта).

#### FR-04 · Логирование в память · [P0 / L / FW]
- Критерии: интервал 0.1 с … 10 мин; режимы «по интервалу», «по событию» (изменение > N %), «ручной» (кнопка — запись); имя сессии, временна́я метка RTC; просмотр списка сессий на приборе с мини-графиком; экспорт CSV через U-диск; статус-индикатор LOG и счётчик записей.
- Реализация: выделить раздел на W25Q128 (минимум 4–8 МБ), кольцевой журнал с wear-leveling; формат записи 16 байт: timestamp(4) · float value(4) · mode/range/flags(2) · aux(4) · crc(2). 8 МБ ≈ 500 000 записей; при 1 Гц — 5.8 суток.
- Тренд-график сделать окном над этим же буфером: масштаб от 160 мс/дел до часов/дел.

#### FR-05 · Сглаживание и скорость отсчётов · [P1 / S / FW]
- Критерии: Smoothing Off / Low / High (экспоненциальный фильтр), скорость дисплея 2.5 / 5 / 10 Гц; настройка per-функция и глобальная.
- Последняя цифра перестаёт «гулять» на 60000 отсчётах (жалоба jebem).

#### FR-06 · Пороги Hi/Lo (Limits) · [P1 / S / FW]
- Критерии: верхний/нижний порог, звук + смена цвета главной цифры при выходе; работает совместно с логированием (запись события).

#### FR-07 · AC-фильтр / VFD-режим · [P2 / M / FW или HW]
- LPF ~1 кГц для измерений на выходе частотников. Если АЦП HY3131 отдаёт достаточно быстрый поток — цифровой фильтр; иначе требует аппаратного RC — отметить как HW.

#### FR-08 · dBm / dBV · [P2 / S / FW]
- Отображение в Aux, выбор опорного сопротивления 50/75/600 Ом.

#### FR-09 · Относительные измерения · [P1 / S / FW]
- REL не сбрасывать при смене предела; REL с сохранением offset per-функция (например, нуль щупов для Ω и паразитная ёмкость для C — хранить в настройках); индикация величины offset.

### 4.2 Питание и сессия

#### FR-10 · Автовыключение по бездействию · [P0 / S / FW]
- Критерии: таймер сбрасывается от: касания, изменения показания > N отсчётов, активного HOLD/AHOLD, MIN/MAX, логирования, BT-соединения, USB. Предупреждение за 30 с с возможностью отменить тапом. Настройка «никогда» при внешнем питании.
- Это самая частая жалоба владельцев: прибор выключается посреди прозвонки.

#### FR-11 · Измерения во время зарядки · [P1 / S / FW]
- Разрешить DMM при подключённом USB (домен изолирован, см. 1.2); показывать предупреждение только в режимах осциллографа/генератора (земля общая с USB). Индикация зарядки в статус-баре не должна закрывать Aux.

#### FR-12 · Затемнение экрана по активности · [P1 / S / FW]
- Тот же источник событий, что в FR-10; отдельная яркость «тусклый режим» вместо выключения подсветки.

### 4.3 Навигация и интерфейс

#### FR-13 · Память подрежима на функцию · [P0 / S / FW]
- При возврате в функцию восстанавливать: подрежим (DC/AC/AC+DC, диод/прозвонка, Hz/T), предел (AUTO/ручной), REL, настройки фильтра. Сброс только явный (долгое нажатие).

#### FR-14 · Прямой доступ к 8 функциям · [P0 / M / FW]
- Варианты (выбрать после прототипа на экране 480×320):
  - a) 8 кнопок в нижней строке (ширина 60 px каждая — на грани, но реалистично);
  - b) 6 кнопок + долгое нажатие открывает всплывающий выбор подрежима;
  - c) свайп влево/вправо по области показания = следующий/предыдущий подрежим.
- Цель: любая функция ≤ 1 касания, любой подрежим ≤ 2.

#### FR-15 · Поворот интерфейса · [P1 / M / FW]
- 0/90/180/270° в настройках; портретная раскладка (корпус портретный, подставка вращается); акселерометра нет — только ручной выбор.

#### FR-16 · Галерея скриншотов и логов · [P1 / M / FW]
- Просмотр, удаление, переименование на приборе. Имя файла с режимом и временем RTC (`2026-10-13_14-22-07_VDC.png`). Формат PNG (если сейчас BMP — сжатие экономит флеш).

#### FR-17 · «Большие кнопки» и управление в перчатках · [P2 / S / FW]
- Режим с увеличенными зонами касания, минимумом элементов, без жестов. Тач в перчатках всё равно не заработает — это HW; но режим снижает число промахов.

#### FR-18 · Замок тача · [P2 / S / FW]
- Авто-замок через N секунд в режимах HOLD/логирования; разблокировка свайпом с подтверждением.

#### FR-19 · Переименование и тексты · [P1 / S / FW]
- «Online/Offline» → «In-circuit (low-V) / Normal» с подсказкой тестового напряжения.
- «Start/Stop» → «HOLD».
- Полный английский (сейчас смесь, особенно в BT-приложении).
- Единицы и обозначения по IEC: Ω, µ, не «u», «R» только в маркировке.

#### FR-20 · Настраиваемые поля Aux · [P2 / S / FW]
- Пользователь выбирает, что показывать в Aux1/Aux2 для каждого подрежима (частота, MIN, MAX, AVG, dBm, REL-offset, время сессии, температура прибора).

### 4.4 Прозвонка, диод, сопротивление

#### FR-21 · Настраиваемая прозвонка · [P1 / S / FW]
- Порог 10 / 25 / 50 / 100 / 200 Ω / 1 kΩ; латч (минимальная длительность сигнала 250 мс даже при касании 1 мс); полноэкранная вспышка цвета как визуальный индикатор; выбор тона.
- Антивибрационная логика: требовать стабильного состояния N мс перед писком — вместо/в дополнение к стоковому «shockproof mode», который жжёт батарею.

#### FR-22 · Диод · [P2 / S / FW]
- Показ тока теста; расширение до 3 В уже есть; добавить «LED-режим» с повышенным напряжением, если HY3131 позволяет. [?]

#### FR-23 · Сопротивление · [P2 / S / FW]
- Отдельная индикация тестового напряжения/тока в Aux; авто-нуль щупов по удержанию кнопки REL.

### 4.5 Ёмкость, частота, температура

#### FR-24 · Ёмкость · [P1 / S / FW]
- Ручной предел; индикатор «заряд…» с прогрессом вместо OL; постоянный REL для паразитной ёмкости прибора (хранить в калибровке, 32 пФ измерено на одном экземпляре).

#### FR-25 · Частотомер · [P2 / S / FW, предел — HW]
- Выбор времени счёта (gate) для разрешения; отображение Aux-частоты во всех режимах V/A; порог/гистерезис, если тракт это позволяет. Чувствительность на 20+ МГц — только HW (усилитель-формирователь).

#### FR-26 · Температура · [P2 / S / FW]
- Выбор типа термопары (K/J/T), пользовательский offset, холодный спай по датчику прибора (уже есть «machine temperature»), °C/°F в Aux.

### 4.6 Генератор и осциллограф (в части, влияющей на DMM-UX)

#### FR-27 · Генератор не выключать в режиме DMM · [P1 / M / FW]
- Сейчас выключается при переходе в DMM (jebem). Домены разные, электрически допустимо. Разобраться, какой ресурс конфликтует (DAC/таймер/DMA). [?]

#### FR-28 · Регулируемый DC-offset · [P1 / S / FW]
- Выход униполярный 0 … 3 В (offset = Vpp/2 фиксирован). В пределах этого диапазона offset можно задавать прошивкой (например, 1 Vpp при 0.5 … 2.5 В). Биполярный выход — HW.
- Режим «DC-источник» 0 … 3 В с шагом 1 мВ — полезен для калибровки и как опора.

#### FR-29 · Единицы амплитуды · [P2 / S / FW]
- Vpp / Vrms / dBu / dBm.

#### FR-30 · Быстрое переключение осциллограф ↔ генератор · [P2 / S / FW]
- Кнопка или жест; панель генератора внутри экрана осциллографа.

#### FR-31 · Генератор как опорный канал осциллографа · [P2 / M / FW]
- Отрисовка заданной формы вторым цветом и/или синхронизация триггера от генератора.

#### FR-32 · Произвольная форма · [P2 / M / FW]
- Загрузка CSV/бинарной таблицы через U-диск; sweep; burst.

### 4.7 Связь и данные

#### FR-33 · USB composite: MSC + CDC · [P1 / M / FW]
- Виртуальный COM с текстовым протоколом (SCPI-подобным): `MEAS?`, `CONF:VOLT:DC`, поток показаний с метками времени; совместимость с sigrok/собственным ПО. U-диск сохранить.

#### FR-34 · BT-протокол · [P1 / S / FW]
- Сохранить совместимость с реверснутым протоколом (DM40GUI, Maj113) и задокументировать; добавить команды управления (переключение функций уже реверсят), поток логов, экспорт CSV из приложения.
- Стабильный Device ID (сейчас периодически отдаёт нули — Maj113).

#### FR-35 · Экспорт CSV из DMM · [P1 / S / FW]
- Сейчас CSV только у осциллографа. Логи и ячейки памяти → CSV с заголовком (прибор, серийник, режим, предел, время).

#### FR-38 · Режим регистратора (быстрый стрим) · [P1 / M / FW]
Отдельный режим, в котором показания уходят наружу на максимально возможной скорости, а точность и разрешение сознательно приносятся в жертву скорости (самый быстрый режим преобразования АЦП, меньше разрядов). Нужен для захвата быстрых процессов (просадки питания, пусковые токи, медленные переходные), где 2–10 отсчётов/с не годятся, а осциллограф не подходит из-за гальванической связи или малой длительности записи.
- Критерии: каждый отсчёт несёт метку времени самого прибора (счётчик мкс или мс на момент преобразования) и сквозной номер; интервал между отсчётами постоянен — без случайных задержек и пауз из-за перерисовки экрана, тача или другой работы прибора; потеря отсчёта (переполнение буфера, обрыв связи) обнаруживается по меткам и номерам, а не пропускается молча; отсчёты читаются хостом по USB (FR-33) и, где позволяет пропускная способность, по BT (FR-34); на экране — только минимальная индикация (LOG/STREAM, счётчик отсчётов, частота), основное показание и график обновляются редко.
- Заметки: реальная максимальная частота и число разрядов в этом режиме зависят от HY3131 и канала SPI через изолятор — указать в документации измеренные значения; согласуется с FR-04 (запись в память) и FR-35 (CSV с метками времени).

### 4.8 Калибровка и сервис

#### FR-36 · Сервисное меню калибровки · [P1 / M / FW]
- Защищённый паролем доступ; пошаговая калибровка по эталонам; хранение констант с резервной копией; экспорт/импорт констант через U-диск. **Критично для кастомной прошивки:** стоковые константы надо прочитать и сохранить до первой перепрошивки.

#### FR-37 · Самодиагностика · [P2 / S / FW]
- Напряжение батареи, температура, состояние реле, версия HW/FW, часы работы, счётчик циклов реле.

## 5. Что проверить на железе до начала работы

1. **Чтение flash MCU.** Защита от чтения (RDP) на GD32F427 через SWD (4-pin разъём V-D-C-G). Если закрыто — путь только через стоковый механизм обновления (bin на U-диск) и анализ формата bin.
2. **Формат обновления.** `dm40xxx.bin` на U-диске: шифрование, подпись, заголовок, кто пишет во flash — bootloader в MCU или загрузчик из W25Q128. Снять дамп W25Q128 (SPI-клипса) до любых экспериментов.
3. **Калибровочные константы.** Где лежат (option bytes MCU, W25Q128, EEPROM-эмуляция). Сохранить образ.
4. **HY3131.** Datasheet Hycon (регистровая карта, конфигурация АЦП, тест-токи); убедиться, что SPI действительно идёт через CA-IS3741; найти пины INT/управления реле.
5. **Тач-контроллер.** Маркировка на шлейфе или I²C-адрес логическим анализатором: `0x5D/0x14` → Goodix GT9xx, `0x38` → FocalTech FT6x36/FT5x06, `0x15` → CST816, `0x1A` → CST3xx.
6. **LCD-драйвер.** ID по команде `RDDID (0x04)` / `RDID4 (0xD3)`; интерфейс (FSMC 16-bit или SPI).
7. **BT.** Интерфейс к BP2A838 (UART?), скорость, протокол — взять за основу реверс из DM40GUI.
8. **Изоляция.** Развязка DMM подтверждена владельцем 2026-10-24; прозвонка USB GND ↔ MCX GND ↔ COM — в [hw/README.md, Isolation boundary](../hw/README.md#isolation-boundary).
9. **Генератор.** Какой DAC-канал и таймер; почему выключается в DMM.
10. **3PA1030.** Куда идёт параллельная шина (GPIO + DMA по таймеру или FSMC), какой клок.
11. **Peak.** Реальная скорость быстрых АЦП HY3131 в конфигурации платы.

## 6. Риски

- **Кирпич.** Без дампа W25Q128 и чтения flash MCU откат невозможен. Первым делом — полный бэкап обоих.
- **Потеря калибровки.** Константы DMM уникальны для экземпляра; TC1746B6 0.1 % помогает, но ±(0.03 % + 5d) без констант не получить.
- **BT-чип.** Datasheet Jieli недоступен; протокол команд к чипу неизвестен — опираться на снифф UART.
- **Безопасность.** Любая ошибка в управлении реле/MOSFET токового тракта при подключённых щупах — это сгоревший предохранитель в лучшем случае. Защитные блокировки (нельзя включить токовый шунт в режиме V) реализовать первыми и покрыть тестами.
- **Тач без физических кнопок.** Если прошивка зависла — выключить можно только долгим нажатием питания; watchdog обязателен.

## Приложение B. Алгоритм AutoHold (набросок)

```
state = IDLE
on each ADC sample v (full rate):
    if OL: state = IDLE; continue
    push v to window W (last T_stable = 1.0 s)
    if state == IDLE:
        if |v - held| > 2% * range:           # сигнал изменился
            state = SETTLING; t0 = now
    elif state == SETTLING:
        if spread(W) <= Y counts and now - t0 >= T_stable:
            held = mean(W); beep(); display(held); state = IDLE
        elif spread(W) > Y counts:
            t0 = now                           # ещё не стабилизировалось
```
Параметры 2 % / Y / T_stable — в настройках; для Ω и C пороги отдельные (медленные измерения).

## Приложение C. Формат записи лога (предложение)

```
struct LogRec {           // 16 байт, little-endian
    uint32_t t;           // секунды Unix или мс от старта сессии
    float    value;       // основное показание в базовых единицах (В, А, Ом, Ф, Гц, °C)
    uint8_t  func;        // 0=VDC 1=VAC 2=VACDC 3=ADC 4=AAC ... 
    uint8_t  range;       // индекс предела; 0xFF = AUTO
    uint8_t  flags;       // bit0 OL, bit1 REL, bit2 HOLD, bit3 limit_hi, bit4 limit_lo
    uint8_t  aux_type;    // что лежит в aux
    float    aux;         // частота / DC-компонента / и т.п.
    // crc16 — на блок 256 байт, не на запись
};
```
